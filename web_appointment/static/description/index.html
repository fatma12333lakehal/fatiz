Web Appointment Module

Overview

The Web Appointment module allows clients to book appointments directly from the website in a simple and efficient way. It is fully integrated with Odoo backend modules such as HR, Project, Calendar, and Mail.

Key Features

  • Online appointment booking from website
  • Automatic synchronization with Odoo Calendar
  • Integration with HR and Project modules
  • Availability management for users
  • Email notifications via Mail module
  • Clean and responsive UI

How It Works

  • Client visits the website
  • Selects available time slot
  • Books appointment instantly
  • Appointment is stored in Odoo Calendar
  • Notifications are sent automatically

Requirements

  • Odoo Website
  • HR Module
  • Project Module
  • Calendar Module
  • Mail Module
